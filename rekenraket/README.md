# 🚀 Rekenraket

Een vrolijke reken-webapp voor kinderen in groep 4. Oefen plussen, minnen, tafels en meer, gewoon op je telefoon.

Onderdeel van de Lanceerbasis (zie de README in de hoofdmap).

## Lokaal draaien

Start een simpele server in de hoofdmap van de Lanceerbasis en open http://localhost:8010/rekenraket/:

```bash
python3 -m http.server 8010
```
